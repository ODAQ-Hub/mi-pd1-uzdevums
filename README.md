# mi-pd1-uzdevums

## Apraksts

"Mani uzdevumi" ir vienkārša uzdevumu saraksta tīmekļa lietotne, kas izveidota ar bezmaksas MI čata palīdzību.
Lietotne var pievienot, atzīmēt kā izpildītus, dzēst un filtrēt uzdevumus, un skaitītājs rāda atlikušo uzdevumu skaitu.
Dati tiek saglabāti pārlūka localStorage atslēgā `pd1-uzdevums`, tāpēc tie saglabājas arī pēc lapas pārkraušanas.
Lietotne izmanto tikai HTML, CSS un JavaScript bez bibliotēkām un darbojas bez servera un interneta savienojuma.

## Palaišana

1. Lejupielādē vai klonē repozitoriju: `git clone https://github.com/ODAQ-Hub/mi-pd1-uzdevums.git`
2. Atver mapi `mi-pd1-uzdevums` un ar dubultklikšķi atver failu `index.html` pārlūkā Chrome,Brave vai Firefox.
3. Serveris vai papildu instalācija nav nepieciešama.

## Papildfunkcija

Izvēlēts variants **A – rediģēšana**: dubultklikšķis uz uzdevuma teksta ļauj to mainīt, Enter saglabā izmaiņas, Esc atceļ.

## Izmantotais MI rīks

ChatGPT (bezmaksas plāns). Visas izmantotās uzvednes ir failā `uzvednes.md`, bet MI darba žurnāls – darba lapas tabulā T1.

## Pārbaudes rezultāti
Visas pārbaudes izdevās. Viens uzlabojums neizdevās, tika atjaunota iepriekšējā versija ar git .
